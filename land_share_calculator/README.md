# Punjab Land Share Calculator

Beautiful PySide6 replacement for the supplied Tkinter calculator.

Features: exact Fraction arithmetic, unlimited co-sharers, share validation,
remaining share, automatic Killa-Kanal-Marla-Sarshai display, summary cards,
calculation preview, example data, add/remove rows, Excel/CSV export,
keyboard shortcuts, and Unicode Hindi/Punjabi support.

Area rules from the original: 1 Kanal = 20 Marlas; 1 Killa = 8 Kanals = 160
Marlas; 1 Marla = 9 Sarshai.

Install: `pip install -r requirements.txt`
Run: `python land_share_calculator.py`
